### DML——介绍

DML 的英文全称是 **Data Manipulation Language（数据操作语言）**，用于对数据库表中的数据记录进行增、改、删操作。

- 添加数据：`INSERT`
- 修改数据：`UPDATE`
- 删除数据：`DELETE`

### DML——添加数据

## 1. 给指定字段添加数据

```
INSERT INTO 表名 (字段名1, 字段名2, ...)
VALUES (值1, 值2, ...);
```

示例：

```
INSERT INTO tb_user (id, name)
VALUES (1, '张三');
```

字段与值必须按照顺序一一对应。

## 2. 给全部字段添加数据

```
INSERT INTO 表名
VALUES (值1, 值2, ...);
```

示例：

```
INSERT INTO tb_user
VALUES (2, '李四', 22, '男');
```

值的数量和顺序必须与表中的全部字段完全一致。

## 3. 批量添加数据

指定字段：

```
INSERT INTO 表名 (字段名1, 字段名2, ...)
VALUES
    (值1, 值2, ...),
    (值1, 值2, ...),
    (值1, 值2, ...);
```

示例：

```
INSERT INTO tb_user (id, name, age, gender)
VALUES
    (3, '王五', 25, '男'),
    (4, '赵六', 19, '女'),
    (5, '小明', 21, '男');
```

全部字段：

```
INSERT INTO 表名
VALUES
    (值1, 值2, ...),
    (值1, 值2, ...);
```

注意：

- 字符串和日期需要使用英文单引号，例如 `'张三'`。
- 数字通常不需要引号。
- 多条数据之间用英文逗号分隔。
- 推荐明确写出字段名，代码更清晰，也不容易受表结构调整影响。

### DML——修改数据

语法：

```
UPDATE 表名
SET 字段名1 = 值1, 字段名2 = 值2, ...
[WHERE 条件];
```

### DML——删除数据

语法：

```
DELETE FROM 表名 [WHERE 条件];
```
