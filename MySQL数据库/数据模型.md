##  MySQL 启动

```
net start mysql80
net stop mysql80
```

## MySQL 客户端连接

MySQL 自带的客户端命令行：

```
mysql [-h 127.0.0.1] [-P 3306] -u root -p
```


## MySQL数据库

### 关系型数据库（RDBMS）

**概念：**  
建立在关系模型基础上，由多张相互连接的二维表组成的数据库。

**特点：**

1. 使用表存储数据，格式统一，便于维护。
2. 使用 SQL 语言操作，标准统一，使用方便。
