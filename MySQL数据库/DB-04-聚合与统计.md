# DB-04：聚合与统计

> 本节目标：使用聚合函数计算整体和分组统计，理解 `WHERE` 与 `HAVING` 的职责，并能完成条件聚合和日期分组。

## 1. COUNT 统计行数

统计所有记录：

```sql
SELECT COUNT(*) AS document_count
FROM documents;
```

统计状态为 `ready` 的活动文档：

```sql
SELECT COUNT(*) AS ready_document_count
FROM documents
WHERE deleted_at IS NULL
  AND status = 'ready';
```

区别：

- `COUNT(*)` 统计符合条件的行数。
- `COUNT(column)` 只统计该列不为 `NULL` 的行。

统计业务记录数量时通常使用 `COUNT(*)`。别名中的 `AS` 可以省略，但写成 `AS ready_document_count` 更清晰；`asready_document_count` 会被理解成另一个别名。

## 2. SUM、AVG、MAX 与 MIN

当前只使用已有的 `documents` 表。先计算正文字符数，再进行聚合：

```sql
SELECT
    SUM(CHAR_LENGTH(raw_content)) AS total_characters,
    AVG(CHAR_LENGTH(raw_content)) AS average_characters,
    MAX(CHAR_LENGTH(raw_content)) AS maximum_characters,
    MIN(CHAR_LENGTH(raw_content)) AS minimum_characters
FROM documents
WHERE deleted_at IS NULL;
```

- `SUM`：求和。
- `AVG`：求平均值。
- `MAX`：最大值。
- `MIN`：最小值。

这些函数通常忽略 `NULL`。`SELECT` 最后一个表达式后不能保留逗号。

## 3. GROUP BY 分组

按状态分别统计：

```sql
SELECT
    status,
    COUNT(*) AS document_count,
    SUM(CHAR_LENGTH(raw_content)) AS total_characters
FROM documents
WHERE deleted_at IS NULL
GROUP BY status;
```

处理过程：

```text
WHERE deleted_at IS NULL
→ GROUP BY status
→ 对每组执行 COUNT 和 SUM
```

`COUNT(CHAR_LENGTH(raw_content))` 只会统计正文长度表达式不为 `NULL` 的行数；要求总字符数时必须使用 `SUM(CHAR_LENGTH(raw_content))`。

在严格分组规则下，`SELECT` 中没有放进聚合函数的普通列，应当出现在 `GROUP BY` 中。

## 4. WHERE 与 HAVING

- `WHERE`：分组前筛选原始行。
- `HAVING`：分组后筛选统计结果。

只保留至少有两篇活动文档的状态：

```sql
SELECT
    status,
    COUNT(*) AS document_count
FROM documents
WHERE deleted_at IS NULL
GROUP BY status
HAVING COUNT(*) >= 2
ORDER BY document_count DESC, status ASC;
```

不能把 `COUNT(*) >= 2` 写进 `WHERE`，因为执行 `WHERE` 时还没有完成分组计数。

相关子句的书写顺序：

```text
WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
```

关键字之间必须有空格或换行，例如不能写成 `2order`。

## 5. 条件聚合

把多个状态的统计放在同一行：

```sql
SELECT
    COUNT(*) AS document_count,
    SUM(
        CASE
            WHEN status = 'ready' THEN 1
            ELSE 0
        END
    ) AS ready_document_count,
    SUM(
        CASE
            WHEN status = 'pending' THEN 1
            ELSE 0
        END
    ) AS pending_document_count
FROM documents
WHERE deleted_at IS NULL;
```

每行满足条件时产生 `1`，否则产生 `0`，最后由 `SUM` 相加。

- `GROUP BY status`：每种状态返回一行。
- 条件聚合：每种状态成为同一行中的一列。

每个条件统计都要有自己完整的 `SUM(CASE ... END)`。

## 6. 日期分组

`DATE(created_at)` 从日期时间中取出日期：

```sql
SELECT
    DATE(created_at) AS created_date,
    COUNT(*) AS document_count
FROM documents
WHERE deleted_at IS NULL
GROUP BY DATE(created_at)
HAVING COUNT(*) >= 2
ORDER BY created_date DESC;
```

项目中的 `DATETIME(6)` 约定保存 UTC，因此这里按 UTC 日期分组。按用户当地日期统计时必须先明确时区转换规则。

## 7. 本轮易错点

- `AS` 与别名粘在一起，得到错误的结果列名。
- 统计总字符数时误用 `COUNT`，正确函数是 `SUM`。
- `SELECT` 最后一项后保留逗号，导致 `FROM` 前出现语法错误。
- 把 `HAVING` 放到 `ORDER BY` 后面。
- 漏写题目要求的 `HAVING COUNT(*) >= 2`。
- 写成 `2order`，关键字之间没有空格。
- 条件聚合的第二个 `CASE` 外漏写 `SUM(`。
- 条件聚合别名与 `FROM` 粘在一起。

检查方法：先确定统计范围，再依次检查“筛行、分组、计算、筛组、排序”。
