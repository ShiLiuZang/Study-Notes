

MySQL 提供了多种数值函数，可用于取整、取模、生成随机数和四舍五入等操作。

## 1. 常用数值函数

| 函数 | 功能 |
|---|---|
| `CEIL(x)` | 向上取整，返回大于或等于 `x` 的最小整数 |
| `FLOOR(x)` | 向下取整，返回小于或等于 `x` 的最大整数 |
| `MOD(x, y)` | 返回 `x` 除以 `y` 的余数 |
| `RAND()` | 返回一个大于或等于 `0`、小于 `1` 的随机数 |
| `ROUND(x, y)` | 对 `x` 进行四舍五入，并保留 `y` 位小数 |

## 2. 使用示例

```sql
-- 向上取整，结果为 2
SELECT CEIL(1.2);

-- 向下取整，结果为 1
SELECT FLOOR(1.8);

-- 取模，结果为 1
SELECT MOD(7, 3);

-- 生成 [0, 1) 范围内的随机数
SELECT RAND();

-- 四舍五入并保留两位小数，结果为 3.14
SELECT ROUND(3.14159, 2);
```

## 3. 注意事项

- `CEIL()` 也可以写作 `CEILING()`。
- `MOD(x, y)` 等价于表达式 `x % y`。
- `RAND()` 每次调用通常会返回不同的随机数；使用相同的种子调用 `RAND(seed)`，可以得到可重复的随机数序列。
- `ROUND(x, 0)` 将 `x` 四舍五入到整数；参数 `y` 为负数时，会对小数点左侧的位数进行四舍五入。
