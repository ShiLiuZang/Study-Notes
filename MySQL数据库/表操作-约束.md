

## 1. 约束概述

约束是作用于表中字段的规则，用于限制存储在表中的数据。

约束的目的是保证数据库中数据的正确性、有效性和完整性。

## 2. 约束分类

| 约束 | 描述 | 关键字 |
|---|---|---|
| 非空约束 | 限制该字段的值不能为 `NULL` | `NOT NULL` |
| 唯一约束 | 保证该字段的所有非空数据唯一、不重复 | `UNIQUE` |
| 主键约束 | 一行数据的唯一标识，要求非空且唯一 | `PRIMARY KEY` |
| 默认约束 | 保存数据时，如果没有指定该字段的值，则采用默认值 | `DEFAULT` |
| 检查约束 | 保证字段值满足指定条件 | `CHECK` |
| 外键约束 | 在两张表之间建立联系，保证数据的一致性和完整性 | `FOREIGN KEY` |

> MySQL 从 8.0.16 开始真正执行 `CHECK` 约束；更早的版本会解析其语法，但可能不会执行检查。

## 3. 创建表时添加约束

```sql
CREATE TABLE user (
    id       INT PRIMARY KEY AUTO_INCREMENT,
    name     VARCHAR(20) NOT NULL,
    username VARCHAR(20) UNIQUE,
    age      INT CHECK (age > 0 AND age <= 120),
    status   CHAR(1) DEFAULT '1'
);
```

上述字段约束的含义：

- `id`：主键，非空且唯一，并自动递增。
- `name`：不能为空。
- `username`：不能重复。
- `age`：必须大于 `0` 且不超过 `120`。
- `status`：未指定值时默认为 `'1'`。

## 4. 表级约束

约束也可以统一写在字段列表之后，并通过 `CONSTRAINT` 为约束命名：

```sql
CREATE TABLE user (
    id       INT,
    username VARCHAR(20),
    age      INT,

    CONSTRAINT pk_user PRIMARY KEY (id),
    CONSTRAINT uk_user_username UNIQUE (username),
    CONSTRAINT chk_user_age CHECK (age > 0 AND age <= 120)
);
```

联合主键或联合唯一约束必须使用表级写法：

```sql
CREATE TABLE course_selection (
    student_id INT,
    course_id  INT,
    score      DECIMAL(5, 2),
    PRIMARY KEY (student_id, course_id)
);
```

## 5. 外键约束

外键用于让子表中的字段引用父表的主键或唯一键。

```sql
CREATE TABLE department (
    id   INT PRIMARY KEY,
    name VARCHAR(50) NOT NULL
);

CREATE TABLE employee (
    id      INT PRIMARY KEY,
    name    VARCHAR(50) NOT NULL,
    dept_id INT,
    CONSTRAINT fk_employee_department
        FOREIGN KEY (dept_id) REFERENCES department(id)
);
```

只有父表 `department` 中已经存在相应的 `id`，才能在子表 `employee` 中保存对应的 `dept_id`。

## 6. 修改表时添加约束

```sql
-- 添加非空约束
ALTER TABLE user
MODIFY name VARCHAR(20) NOT NULL;

-- 添加唯一约束
ALTER TABLE user
ADD CONSTRAINT uk_user_username UNIQUE (username);

-- 添加主键约束
ALTER TABLE user
ADD CONSTRAINT pk_user PRIMARY KEY (id);

-- 添加检查约束
ALTER TABLE user
ADD CONSTRAINT chk_user_age CHECK (age > 0 AND age <= 120);

-- 添加外键约束
ALTER TABLE employee
ADD CONSTRAINT fk_employee_department
FOREIGN KEY (dept_id) REFERENCES department(id);
```

## 7. 注意事项

- 一张表只能有一个主键，但主键可以由多个字段共同组成。
- `PRIMARY KEY` 自带 `NOT NULL` 和唯一性要求。
- `UNIQUE` 通常允许多个 `NULL` 值，因为 `NULL` 不被视为彼此相等。
- `DEFAULT` 只在插入数据时未指定该字段的情况下生效；显式插入 `NULL` 时是否成功取决于字段是否允许为空。
- 添加约束前，表中已有数据也必须满足该约束，否则操作会失败。
- 外键字段和被引用字段的数据类型应保持一致或兼容。
