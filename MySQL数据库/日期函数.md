

MySQL 的日期函数可用于获取当前日期和时间、提取日期部分，以及进行日期计算。

## 1. 常用日期函数

| 函数 | 功能 |
|---|---|
| `CURDATE()` | 返回当前日期 |
| `CURTIME()` | 返回当前时间 |
| `NOW()` | 返回当前日期和时间 |
| `YEAR(date)` | 获取指定日期 `date` 的年份 |
| `MONTH(date)` | 获取指定日期 `date` 的月份 |
| `DAY(date)` | 获取指定日期 `date` 是当月的第几日 |
| `DATE_ADD(date, INTERVAL expr type)` | 返回日期或时间 `date` 加上指定时间间隔后的值 |
| `DATEDIFF(date1, date2)` | 返回 `date1` 与 `date2` 相差的天数，即 `date1 - date2` |

## 2. 使用示例

```sql
-- 获取当前日期、时间以及日期和时间
SELECT CURDATE();
SELECT CURTIME();
SELECT NOW();

-- 提取日期中的年、月、日
SELECT YEAR('2026-08-04');  -- 2026
SELECT MONTH('2026-08-04'); -- 8
SELECT DAY('2026-08-04');   -- 4

-- 在指定日期上增加 10 天，结果为 2026-08-14
SELECT DATE_ADD('2026-08-04', INTERVAL 10 DAY);

-- 在指定日期上增加 2 个月，结果为 2026-10-04
SELECT DATE_ADD('2026-08-04', INTERVAL 2 MONTH);

-- 计算两个日期相差的天数，结果为 9
SELECT DATEDIFF('2026-08-10', '2026-08-01');
```

## 3. 常用时间间隔单位

| 单位 | 含义 |
|---|---|
| `DAY` | 天 |
| `WEEK` | 周 |
| `MONTH` | 月 |
| `QUARTER` | 季度 |
| `YEAR` | 年 |
| `HOUR` | 小时 |
| `MINUTE` | 分钟 |
| `SECOND` | 秒 |

## 4. 注意事项

- `CURDATE()` 的返回格式通常为 `YYYY-MM-DD`。
- `CURTIME()` 的返回格式通常为 `HH:MM:SS`。
- `NOW()` 的返回格式通常为 `YYYY-MM-DD HH:MM:SS`。
- `DATEDIFF(date1, date2)` 按照 `date1 - date2` 计算；当 `date1` 早于 `date2` 时，结果为负数。
- `DATEDIFF()` 只计算日期部分的天数差，会忽略参数中的时间部分。
- 使用负数时间间隔可以实现日期减法，例如 `DATE_ADD('2026-08-04', INTERVAL -1 DAY)`。
