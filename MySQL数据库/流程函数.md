

流程函数可以根据条件返回不同的结果，常用于在 SQL 查询中实现分支判断和结果转换。

## 1. 常用流程函数

| 函数或表达式 | 功能 |
|---|---|
| `IF(value, t, f)` | 如果 `value` 为真，则返回 `t`，否则返回 `f` |
| `IFNULL(value1, value2)` | 如果 `value1` 不为 `NULL`，则返回 `value1`，否则返回 `value2` |
| `CASE WHEN condition THEN result ... ELSE default END` | 依次判断条件；条件为真时返回对应结果，否则返回默认值 |
| `CASE expr WHEN value THEN result ... ELSE default END` | 将 `expr` 与各个 `value` 比较；相等时返回对应结果，否则返回默认值 |

## 2. IF 函数

基本语法：

```sql
IF(条件, 条件为真时的值, 条件为假时的值)
```

示例：

```sql
-- 结果为“及格”
SELECT IF(60 >= 60, '及格', '不及格');

-- 根据员工年龄显示是否成年
SELECT name,
       IF(age >= 18, '成年', '未成年') AS 年龄状态
FROM emp;
```

## 3. IFNULL 函数

基本语法：

```sql
IFNULL(value1, value2)
```

示例：

```sql
-- 结果为“暂无备注”
SELECT IFNULL(NULL, '暂无备注');

-- 将员工表中的 NULL 奖金显示为 0
SELECT name,
       IFNULL(bonus, 0) AS bonus
FROM emp;
```

## 4. CASE 表达式

### 4.1 条件判断形式

适合判断范围或多个不同的条件：

```sql
CASE
    WHEN 条件1 THEN 结果1
    WHEN 条件2 THEN 结果2
    ...
    ELSE 默认值
END
```

示例：

```sql
SELECT name,
       score,
       CASE
           WHEN score >= 90 THEN '优秀'
           WHEN score >= 60 THEN '及格'
           ELSE '不及格'
       END AS 成绩等级
FROM student;
```

### 4.2 等值匹配形式

适合将一个表达式与多个固定值进行比较：

```sql
CASE 表达式
    WHEN 值1 THEN 结果1
    WHEN 值2 THEN 结果2
    ...
    ELSE 默认值
END
```

示例：

```sql
SELECT name,
       CASE workaddress
           WHEN '北京' THEN '一线城市'
           WHEN '上海' THEN '一线城市'
           ELSE '其他城市'
       END AS 城市类别
FROM emp;
```

## 5. 注意事项

- `IF()` 和 `IFNULL()` 是 MySQL 提供的函数，`CASE` 是标准 SQL 表达式，可移植性更好。
- `CASE` 按照书写顺序进行匹配，并返回第一个满足条件的结果。
- `ELSE` 可以省略；没有任何条件匹配且未书写 `ELSE` 时，返回 `NULL`。
- 判断空值应使用 `IS NULL` 或 `IS NOT NULL`，不能使用 `= NULL`。
