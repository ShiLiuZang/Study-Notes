 # 多表查询——连接查询——外连接

## 1. 外连接概述

外连接不仅返回两张表中满足连接条件的数据，还会保留指定一侧未匹配的记录。

- **左外连接**：保留左表的全部数据。
- **右外连接**：保留右表的全部数据。
- 没有匹配数据时，另一侧表的字段显示为 `NULL`。

## 2. 左外连接

左外连接返回左表的所有数据，以及左表和右表中满足连接条件的数据。

基本语法：

```sql
SELECT 字段列表
FROM 表1
LEFT [OUTER] JOIN 表2
    ON 连接条件;
```

`OUTER` 关键字可以省略：

```sql
SELECT 字段列表
FROM 表1
LEFT JOIN 表2
    ON 连接条件;
```

示例：查询所有员工及其所属部门，包括尚未分配部门的员工。

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称
FROM employee e
LEFT JOIN department d
    ON e.dept_id = d.id;
```

如果某位员工没有对应的部门，该员工仍会出现在结果中，其部门名称为 `NULL`。

## 3. 右外连接

右外连接返回右表的所有数据，以及左表和右表中满足连接条件的数据。

基本语法：

```sql
SELECT 字段列表
FROM 表1
RIGHT [OUTER] JOIN 表2
    ON 连接条件;
```

`OUTER` 关键字可以省略：

```sql
SELECT 字段列表
FROM 表1
RIGHT JOIN 表2
    ON 连接条件;
```

示例：查询所有部门及其员工，包括暂时没有员工的部门。

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称
FROM employee e
RIGHT JOIN department d
    ON e.dept_id = d.id;
```

如果某个部门没有员工，该部门仍会出现在结果中，其员工姓名为 `NULL`。

## 4. 左外连接与右外连接的转换

交换两张表的位置后，右外连接通常可以改写为左外连接。

以下两条 SQL 的查询结果相同：

```sql
SELECT e.name, d.name
FROM employee e
RIGHT JOIN department d
    ON e.dept_id = d.id;
```

```sql
SELECT e.name, d.name
FROM department d
LEFT JOIN employee e
    ON e.dept_id = d.id;
```

实际开发中通常优先使用 `LEFT JOIN`，可以让多表查询的阅读方向更加统一。

## 5. 查询未匹配的数据

### 5.1 查询没有部门的员工

```sql
SELECT e.id,
       e.name
FROM employee e
LEFT JOIN department d
    ON e.dept_id = d.id
WHERE d.id IS NULL;
```

### 5.2 查询没有员工的部门

```sql
SELECT d.id,
       d.name
FROM department d
LEFT JOIN employee e
    ON d.id = e.dept_id
WHERE e.id IS NULL;
```

这种“外连接 + `IS NULL`”的写法常用于查找孤立数据或不存在关联记录的数据。

## 6. ON 与 WHERE 的区别

在外连接中，条件写在 `ON` 还是 `WHERE` 中可能会改变查询结果。

### 6.1 条件写在 ON 中

查询所有部门，并只匹配年龄大于等于 30 岁的员工：

```sql
SELECT d.name AS 部门名称,
       e.name AS 员工姓名
FROM department d
LEFT JOIN employee e
    ON d.id = e.dept_id
   AND e.age >= 30;
```

所有部门都会被保留。没有符合年龄条件的员工时，员工字段显示为 `NULL`。

### 6.2 条件写在 WHERE 中

```sql
SELECT d.name AS 部门名称,
       e.name AS 员工姓名
FROM department d
LEFT JOIN employee e
    ON d.id = e.dept_id
WHERE e.age >= 30;
```

`WHERE` 会在连接完成后过滤结果。右表没有匹配记录时，`e.age` 为 `NULL`，无法满足条件，因此相应部门也会被过滤掉。此时查询效果接近内连接。

## 7. 多表外连接

可以继续连接其他表：

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称,
       l.name AS 工作地点
FROM employee e
LEFT JOIN department d
    ON e.dept_id = d.id
LEFT JOIN location l
    ON d.location_id = l.id;
```

该查询始终保留所有员工；没有部门或部门没有工作地点时，相应字段显示为 `NULL`。

## 8. 全外连接

全外连接会保留左右两张表的所有记录，但 MySQL 不直接支持 `FULL OUTER JOIN`。可以使用 `LEFT JOIN`、`RIGHT JOIN` 和 `UNION` 模拟：

```sql
SELECT e.id AS employee_id,
       e.name AS employee_name,
       d.id AS department_id,
       d.name AS department_name
FROM employee e
LEFT JOIN department d
    ON e.dept_id = d.id

UNION

SELECT e.id,
       e.name,
       d.id,
       d.name
FROM employee e
RIGHT JOIN department d
    ON e.dept_id = d.id;
```

`UNION` 会去除两部分查询中重复的匹配记录。

## 9. 内连接与外连接对比

| 连接方式 | 返回内容 |
|---|---|
| `INNER JOIN` | 只返回左右两表匹配成功的数据 |
| `LEFT JOIN` | 返回左表全部数据和匹配成功的右表数据 |
| `RIGHT JOIN` | 返回右表全部数据和匹配成功的左表数据 |

## 10. 注意事项

- `LEFT JOIN` 中，`LEFT` 左侧的表是需要完整保留的表。
- `RIGHT JOIN` 中，`RIGHT` 右侧的表是需要完整保留的表。
- 未匹配一侧的字段值为 `NULL`，判断时应使用 `IS NULL`，不能使用 `= NULL`。
- 外连接中筛选被连接表的数据时，要特别注意条件放在 `ON` 还是 `WHERE` 中。
- 一对多关系可能让一条主表记录在结果中出现多次，这是正常的连接结果。
- 连接字段最好建立索引，以提高大表连接查询的效率。
