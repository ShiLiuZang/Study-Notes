

MySQL 内置了许多字符串函数，可用于字符串拼接、大小写转换、填充、去除空格和截取等操作。

## 1. 常用字符串函数

| 函数 | 功能 |
|---|---|
| `CONCAT(S1, S2, ..., Sn)` | 字符串拼接，将 `S1`、`S2`、……、`Sn` 拼接成一个字符串 |
| `LOWER(str)` | 将字符串 `str` 全部转换为小写 |
| `UPPER(str)` | 将字符串 `str` 全部转换为大写 |
| `LPAD(str, n, pad)` | 左填充，使用字符串 `pad` 在 `str` 左侧进行填充，使结果达到 `n` 个字符的长度 |
| `RPAD(str, n, pad)` | 右填充，使用字符串 `pad` 在 `str` 右侧进行填充，使结果达到 `n` 个字符的长度 |
| `TRIM(str)` | 去掉字符串头部和尾部的空格 |
| `SUBSTRING(str, start, len)` | 返回字符串 `str` 从 `start` 位置起、长度为 `len` 的子字符串 |

## 2. 使用示例

```sql
-- 字符串拼接，结果为 Hello MySQL
SELECT CONCAT('Hello', ' ', 'MySQL');

-- 大小写转换
SELECT LOWER('Hello MySQL'); -- hello mysql
SELECT UPPER('Hello MySQL'); -- HELLO MYSQL

-- 左右填充
SELECT LPAD('01', 5, '-'); -- ---01
SELECT RPAD('01', 5, '-'); -- 01---

-- 去除字符串两端的空格
SELECT TRIM('  Hello MySQL  '); -- Hello MySQL

-- 从第 1 个字符开始截取 5 个字符
SELECT SUBSTRING('Hello MySQL', 1, 5); -- Hello
```

## 3. 注意事项

- `SUBSTRING` 的字符位置从 `1` 开始计算。
- 当 `LPAD` 或 `RPAD` 指定的长度 `n` 小于原字符串长度时，返回值会被截取为 `n` 个字符。
- `TRIM(str)` 默认只去除字符串两端的空格，不会删除字符串中间的空格。
- `CONCAT` 的任意一个参数为 `NULL` 时，返回结果为 `NULL`。
