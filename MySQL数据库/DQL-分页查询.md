# DQL——分页查询

分页查询用于分批获取查询结果。在 MySQL 中，使用 `LIMIT` 实现分页。

## 1. 语法

```sql
SELECT 字段列表
FROM 表名
LIMIT 起始索引, 查询记录数;
```

起始索引的计算公式：

```text
起始索引 = (查询页码 - 1) × 每页显示记录数
```

## 2. 常用示例

每页显示 5 条，查询第 1 页：

```sql
SELECT *
FROM emp
LIMIT 0, 5;
```

查询第 1 页时，起始索引 `0` 可以省略：

```sql
SELECT *
FROM emp
LIMIT 5;
```

每页显示 5 条，查询第 2 页：

```sql
SELECT *
FROM emp
LIMIT 5, 5;
```

每页显示 5 条，查询第 3 页：

```sql
SELECT *
FROM emp
LIMIT 10, 5;
```

结合排序查询，按照员工编号稳定分页：

```sql
SELECT *
FROM emp
ORDER BY id ASC
LIMIT 5, 5;
```

## 3. 分页计算示例

假设每页显示 10 条记录：

| 查询页码 | 起始索引 | 写法 |
|---|---:|---|
| 第 1 页 | `0` | `LIMIT 0, 10` 或 `LIMIT 10` |
| 第 2 页 | `10` | `LIMIT 10, 10` |
| 第 3 页 | `20` | `LIMIT 20, 10` |

## 4. 注意事项

- 起始索引从 `0` 开始，而不是从 `1` 开始。
- 查询第 1 页时，起始索引可以省略，例如 `LIMIT 10`。
- 分页查询属于数据库方言，不同数据库的实现方式可能不同；MySQL 使用 `LIMIT`。
- `LIMIT` 通常写在 SQL 语句的最后。
- 实际分页时建议配合 `ORDER BY` 使用，确保每次查询的记录顺序稳定。
