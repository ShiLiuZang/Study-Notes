

## 1. 内连接概述

连接查询用于从两张或多张存在关联关系的表中查询数据。

内连接查询返回两张表中满足连接条件的数据，即两张表数据的交集部分。如果某条记录在另一张表中没有匹配数据，则不会出现在查询结果中。

## 2. 隐式内连接

隐式内连接将多张表写在 `FROM` 子句中，并在 `WHERE` 子句中指定连接条件。

基本语法：

```sql
SELECT 字段列表
FROM 表1, 表2
WHERE 连接条件;
```

示例：查询员工姓名及其所属部门名称。

```sql
SELECT employee.name,
       department.name
FROM employee, department
WHERE employee.dept_id = department.id;
```

## 3. 显式内连接

显式内连接使用 `INNER JOIN ... ON` 指定需要连接的表及连接条件。

基本语法：

```sql
SELECT 字段列表
FROM 表1
[INNER] JOIN 表2 ON 连接条件;
```

`INNER` 关键字可以省略：

```sql
SELECT 字段列表
FROM 表1
JOIN 表2 ON 连接条件;
```

示例：

```sql
SELECT employee.name,
       department.name
FROM employee
INNER JOIN department
    ON employee.dept_id = department.id;
```

## 4. 使用表别名

连接查询中通常使用表别名简化 SQL，并避免不同表中存在同名字段时产生歧义。

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称
FROM employee AS e
INNER JOIN department AS d
    ON e.dept_id = d.id;
```

`AS` 可以省略：

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称
FROM employee e
JOIN department d
    ON e.dept_id = d.id;
```

> 为表指定别名后，当前查询中应使用别名引用该表，不能再使用原表名限定字段。

## 5. 添加筛选条件

显式内连接通常把表之间的关联条件写在 `ON` 中，把查询结果的筛选条件写在 `WHERE` 中。

查询研发部中年龄大于等于 25 岁的员工：

```sql
SELECT e.name AS 员工姓名,
       e.age AS 年龄,
       d.name AS 部门名称
FROM employee e
JOIN department d
    ON e.dept_id = d.id
WHERE d.name = '研发部'
  AND e.age >= 25;
```

这样书写可以清晰地区分：

- `ON`：表与表如何进行匹配。
- `WHERE`：连接结果需要满足什么筛选条件。

## 6. 连接多张表

内连接可以依次连接多张表：

```sql
SELECT e.name AS 员工姓名,
       d.name AS 部门名称,
       l.name AS 工作地点
FROM employee e
JOIN department d
    ON e.dept_id = d.id
JOIN location l
    ON d.location_id = l.id;
```

每增加一张表，通常都需要写出该表与已有表之间的连接条件。

## 7. 隐式与显式内连接对比

| 对比项 | 隐式内连接 | 显式内连接 |
|---|---|---|
| 语法 | `FROM 表1, 表2 WHERE ...` | `FROM 表1 JOIN 表2 ON ...` |
| 连接条件位置 | `WHERE` 子句 | `ON` 子句 |
| 可读性 | 多表连接时较低 | 结构清晰，容易维护 |
| 使用建议 | 适合了解旧式写法 | 实际开发中优先使用 |

两种写法在连接条件相同的情况下，通常能够得到相同的结果。

## 8. 注意事项

- 查询多个表的同名字段时，应使用 `表名.字段名` 或 `表别名.字段名` 明确字段来源。
- 不要遗漏连接条件，否则会产生笛卡尔积，结果行数可能是两张表记录数的乘积。
- 内连接只返回匹配成功的数据，不会保留未匹配的记录。
- 一对多关系中，父表的一条记录可能匹配子表的多条记录，因此查询结果可能出现多行父表信息。
- 连接查询是否需要外键约束并无强制关系；只要字段之间存在可用于匹配的逻辑关系，就可以进行连接查询。
